# 📖 บันทึกการอ่าน

เว็บแอพเล็กๆ สำหรับจดว่าแต่ละวันอ่านหนังสืออะไร ได้อะไรจากการอ่าน และอ่านไปถึงไหนแล้ว

## ความสามารถ

- ชั้นหนังสือพร้อมรูปปก แยกหมวด กำลังอ่าน / ยังไม่ได้อ่าน / อ่านจบแล้ว
- บันทึกจำนวนหน้าทั้งหมดและหน้าที่อ่านแล้ว พร้อมแถบความคืบหน้าเป็นเปอร์เซ็นต์
- จดสิ่งที่ได้จากการอ่านในแต่ละวัน ค้นหาบันทึกเก่าได้
- เก็บคำคมที่ชอบพร้อมเลขหน้า และสุ่มคำคมประจำวันที่หน้าแรก
- ให้ดาว 1–5 และรีวิวสั้นๆ เมื่ออ่านจบ
- ปฏิทินการอ่าน ดูว่าวันไหนอ่านบ้าง
- รองรับโหมดมืดและใช้บนมือถือได้

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

### ขึ้นเว็บด้วย GitHub Pages

1. อัปโหลด `index.html` และ `README.md` ขึ้น repository
2. ไปที่ **Settings → Pages**
3. ตรง **Source** เลือก `Deploy from a branch` แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)`
4. กด **Save** รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## เรื่องข้อมูล

ข้อมูลทั้งหมดเก็บไว้ใน **IndexedDB** ของเบราว์เซอร์ที่ใช้เปิด โดยรูปปกเก็บเป็นไฟล์รูปโดยตรง

- พื้นที่ใหญ่มาก ปกติหลายร้อย MB ขึ้นไปตามพื้นที่ว่างของเครื่อง ใส่ปกได้หลายพันถึงหลายหมื่นเล่ม
- แอพขอให้เบราว์เซอร์เก็บข้อมูลแบบถาวร เพื่อไม่ให้ถูกลบเองตอนเครื่องใกล้เต็ม
- ถ้าเคยใช้เวอร์ชันเก่าที่เก็บใน `localStorage` ข้อมูลจะถูกย้ายมาให้อัตโนมัติตอนเปิดครั้งแรก
- ไม่ส่งข้อมูลไปที่ไหน แต่ก็ไม่ซิงก์ข้ามเครื่องหรือข้ามเบราว์เซอร์
- ถ้าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ บันทึกจะหายไป
- ถ้าเบราว์เซอร์ไม่รองรับ IndexedDB แอพจะกลับไปใช้ `localStorage` แทน
